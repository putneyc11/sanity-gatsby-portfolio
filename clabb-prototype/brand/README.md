# Clabb brand kit

- `brand-board.html` — 3×3 identity board: vessel-C mark (a C thrown around
  a marigold center — the potter's wheel read), construction geometry, app
  icons, tagline board, color ramps, type pairing, studio tag-card mockup,
  image direction, component detail. Self-contained; open in a browser.
- `clabb-brand-board.png` — rendered board (1680px).
- `../design/tokens.css` — the extended token sheet the board draws from.

**Reconciliation note.** This kit was authored as a standalone identity
concept before the app's incumbent tokens were confirmed. Its ramps are
dusk-toned (pine `#1D3126` family) and it proposes "marigold = the one
action." The shipping app system (see repo-root `DESIGN.md`) uses pine
`#22574A`, marigold = ratings, clay = money. The app system is
authoritative for product UI; treat this board as identity-direction
material and reconcile ramps before using it as a spec.

Tagline is binding and never edited: **creative collaboration feeds the soul.**
